## Findings considered and rejected

- **Switch to per-branch cron (ADR-0001):** Would reduce centralized matrix runs
  but requires propagating workflow changes to every tenant branch and conflicts
  with the current centralized `scheduled-backup.yml` architecture. Not minimal
  effort for minutes savings alone.
- **Self-hosted runners:** Eliminates per-minute billing but adds infra cost and
  ops burden — out of scope for workflow-only optimization.
- **Remove backup summary reports:** Saves a job per run but loses operator
  visibility; rejected in favor of skipping summary only when count=0 (plan 004).
